# Meu Turno (PWA)

## 1. Publicar no GitHub Pages
1. Crie um repositório público no GitHub (ex.: `meu-turno`).
2. Envie **todo o conteúdo desta pasta** para a raiz do repositório (`index.html`, `manifest.webmanifest`, `sw.js`, pasta `icons` e `.nojekyll`).
3. No repositório: **Settings > Pages > Build and deployment**. Em *Source* escolha **Deploy from a branch**, branch **main**, pasta **/ (root)**, e salve.
4. Aguarde 1 a 2 minutos. O endereço será `https://SEU-USUARIO.github.io/meu-turno/`. Abra no celular para conferir.

## 2. Gerar o APK no PWABuilder
1. Acesse https://www.pwabuilder.com e cole o endereço do passo 1.
2. Clique em **Start** e depois em **Package for stores > Android**.
3. Confirme os dados (nome: Meu Turno) e baixe o pacote.
4. No zip baixado, o arquivo `.apk` é o que você instala no celular (o `.aab` é só para a Play Store).

## Observações
- Ao instalar o APK, o Android pede para liberar "instalar apps de fontes desconhecidas".
- Horas extras, notas, ramais e ajustes ficam salvos no próprio aparelho.
